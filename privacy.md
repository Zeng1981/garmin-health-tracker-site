Privacy Policy

Last updated: October 22, 2026

Overview

Garmin Health Tracker is a personal-use tool for synchronizing selected Garmin Connect health and fitness data to a Google Sheets spreadsheet for personal tracking and trend analysis.

Data Collection

This website is a static information page. It does not collect, store, or process visitors' personal information through forms, analytics, or tracking tools.

The Garmin Health Tracker script runs on the owner's own computer and retrieves selected health and fitness data from Garmin Connect.

Data Storage and Use

Selected Garmin data is stored locally on the owner's computer and may be written to the owner's Google Sheets spreadsheet. The data is used solely for personal health and fitness tracking and trend analysis.

This website does not receive or store Garmin health records, Google Sheets contents, OAuth tokens, or account passwords.

Google API Access

The application uses the Google Sheets API to create and update the owner's spreadsheet, subject to the permissions granted by the owner through Google's OAuth authorization process.

Google's handling of data accessed through its services is governed by Google's own privacy policies and terms.

Data Sharing

The application is intended for personal use. The owner does not use this website to publish or sell health data. Access to the spreadsheet is controlled separately through the owner's Google account and sharing settings.

Data Security

OAuth credentials and tokens are intended to be stored locally on the owner's computer with restricted file permissions. No credentials or health records should be published in this website's source repository.

Changes to This Policy

This policy may be updated if the application's functionality or data handling practices change.

Contact

For questions about this personal-use application, contact the developer using the contact email listed on the application's Google OAuth consent screen.
