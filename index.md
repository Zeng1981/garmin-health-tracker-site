Garmin Health Tracker

A personal tool for tracking Garmin health and fitness data.

This project is designed for personal use. It helps the owner synchronize selected Garmin Connect health and activity data to a private Google Sheets spreadsheet for personal tracking and trend analysis.

How it works

Garmin data is retrieved by a script running on the owner's own Mac.

Selected data is written to the owner's Google Sheets spreadsheet.

The spreadsheet is managed through the owner's Google account.

This website is a static information page. It does not collect Garmin health data or provide a data-upload service.
